## Циклы

Здесь мы разберём единственную конструкцию цикла в Go — `for`, и как с её помощью писать разные виды повторений.

### Простыми словами
- Цикл — это «повтори действие N раз» или «повторяй, пока условие истинно».
- Классический счётчик: стартуем с числа, каждый круг увеличиваем счётчик, пока не достигнем предела.

### Варианты `for`
- Счётчик: `for init; condition; post { ... }` — как «от i = старт до конца, шаг за шагом».
- Как `while`: `for condition { ... }` — пока условие истинно, крутимся.
- Бесконечный: `for { ... }` — прерывается `break`/`return`.
- Перебор коллекций: `for index, value := range collection { ... }`.

### Под капотом (упрощённо)
- Переменные цикла обычно лежат в стеке; на каждом шаге обновляются.
- Условие проверяется на каждой итерации; если ложь — выходим из цикла.
- Инструкции `break` и `continue` изменяют поток: `break` — выход из цикла, `continue` — переход к следующей итерации.
