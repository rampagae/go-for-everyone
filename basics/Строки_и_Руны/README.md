## Строки и Руны

Строка — это последовательность байтов в кодировке UTF‑8. Руна — это символ (Unicode‑кодовая точка).

### Простыми словами
- `len(str)` — длина в байтах, а не в символах.
- Чтобы пройти по символам, используйте `for _, r := range str` — там `r` будет руной.
- Некоторые символы занимают несколько байтов.

### Как запустить пример
- Откройте терминал в папке `basics/Строки_и_Руны` и выполните:

```bash
go run example.go
```
