## Условия

Здесь разберём, как выполнять разные действия в зависимости от логических условий с помощью `if` и `switch`, и что происходит «под капотом».

### Что такое условие
- Условие — выражение, которое даёт булево значение: `true` или `false`.
- В Go нет «truthy/falsy»: в `if` можно писать только выражения типа `bool`.

### If / else
- Базовая развилка: если условие истинно — выполняем блок `if`, иначе — `else`.
- Поддерживается короткая инициализация: `if x := expr; x > 0 { ... }`. Переменная `x` видна только внутри `if/else`.
- Цепочка ветвлений: `if / else if / else`.

### Switch
- Перебор вариантов без множества `else if`.
- Сравнения в `case` идут сверху вниз; выполняется первый подходящий `case`.
- `break` не нужен — выход из `switch` по умолчанию. Явный `fallthrough` переходит к следующему `case`.
- Бывает без выражения (`switch { ... }`) — тогда в `case` пишут условия.

### Под капотом (упрощённо)
- Компилятор генерирует ветвления: выполняется только та ветка, для которой условие истинно; остальные инструкции пропускаются (прыжки в машинном коде).
- Переменные из короткой инициализации создаются в рамках области `if/switch` (обычно в стеке), за пределами недоступны.
- `switch` может компилироваться как цепочка сравнений; для плотных числовых `case` компилятор может выбирать более быстрые стратегии (например, таблицы переходов).
- Сравнения строк выполняются по длине и содержимому (побайтно), что может быть дороже, чем сравнение чисел.

### Частые ошибки
- Путаница `=` (присваивание) и `==` (сравнение).
- Использование неинициализированных значений в условиях.
- Затенение переменных при короткой инициализации: `if x := ...; ... { ... }` — снаружи `x` не существует.

```bash
go run example_vars_conditions.go
```
