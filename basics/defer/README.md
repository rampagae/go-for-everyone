## defer

`defer` — откладывает выполнение функции до момента выхода из текущей функции. Как «убраться после работы».

### Простыми словами
- Пишем `defer doCleanup()`: вызов `doCleanup` произойдёт в конце, даже если были `return` раньше.
- Полезно для закрытия файлов, снятия блокировок, очистки ресурсов.

### Как запустить пример
- Откройте терминал в папке `basics/defer` и выполните:

```bash
go run example.go
```
