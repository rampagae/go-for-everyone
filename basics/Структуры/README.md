## Структуры (struct)

Структура — это «контейнер» для связанных полей: как карточка человека с именем, возрастом и т. д.

### Простыми словами
- Описываем форму данных: какие поля и каких типов.
- Создаём переменные этого типа и заполняем поля.
- Можно писать методы для работы с такими данными.

### Как запустить пример
- Откройте терминал в папке `basics/Структуры` и выполните:

```bash
go run example.go
```
