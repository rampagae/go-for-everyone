## Тесты

Тест — это функция, которая проверяет, что ваш код делает то, что нужно.

### Простыми словами
- Имя тестовой функции начинается с `Test...` и принимает `*testing.T`.
- Запуск: `go test` (в папке модуля или пакета).
- Если что-то не так — сообщаем через `t.Errorf`/`t.Fatalf`.

### Как запустить пример
- Откройте терминал в папке `basics/Тесты` и выполните:

```bash
go test -v
```
