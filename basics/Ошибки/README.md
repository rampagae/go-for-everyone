## Ошибки

В Go ошибки — обычные значения (тип `error`), которые возвращают функции. Их нужно проверять.

### Простыми словами
- Функция возвращает результат и ошибку: `v, err := do()`.
- Если `err != nil` — что‑то пошло не так, решаем, что делать.
- Ошибка — не исключение; это явная часть результата.

### Как запустить пример
- Откройте терминал в папке `basics/Ошибки` и выполните:

```bash
go run example.go
```
