## Пакеты и Модули

Пакет — папка с кодом, которую можно импортировать. Модуль — проект с файлом `go.mod`, описывает зависимости.

### Простыми словами
- `package main` — точка входа приложения (есть `func main()`).
- Другие пакеты — библиотечный код без `main`, импортируем через `import`.
- `go mod init <module-path>` — создаёт модуль; `go get` — добавляет зависимости.

### Как запустить пример
- Откройте терминал в папке `basics/Пакеты_и_Модули` и выполните:

```bash
go run example.go
```
