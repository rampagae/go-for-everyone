## Функции

Функция — это «мини‑станок» в вашей мастерской кода: вы подаёте на вход материалы (параметры), станок что‑то делает и выдаёт результат (возвращаемые значения). Это помогает не повторять один и тот же код.

### Простыми словами
- Функция — именованная команда «как сделать X».
- Параметры — это входные данные, с которыми функция работает.
- Возвращаемые значения — это результат(ы) работы функции.
- Функции можно вызывать много раз с разными входами — результат будет соответствовать входным данным.

### Базовые элементы
- Имя функции: отражает действие (например, `sum`, `isAdult`).
- Параметры с типами: `func sum(a int, b int)`.
- Возвращаемые значения: одно (`int`) или несколько (`int, error`).
- Область видимости: функции с заглавной буквы видны из других пакетов (экспортируются).

### Обработка ошибок через `error`
- Идиоматичный подход в Go: возвращать `value, error`.
- Если `error != nil` — это сигнал, что что‑то пошло не так; вызывающая сторона решает, как реагировать.

### Под капотом (упрощённо)
- При вызове функции создаётся новый фрейм на стеке: туда кладутся аргументы, локальные переменные и адрес возврата.
- Возврат — это копирование/передача результатов обратно вызывающему коду; для ссылочных типов копируется дескриптор.
- Если функция использует «закрытия» (анонимные функции с внешними переменными), данные могут размещаться в куче, чтобы жить дольше вызова.

### Примеры
- См. `example.go` — простые функции: с параметрами, несколькими возвратами и обработкой ошибок.
- См. `example_vars_conditions_functions.go` — совместно: переменные + условия + функции.

### Как запустить
- Откройте терминал (VS Code или системный) в папке `basics/Функции`.
- Запустите конкретный файл:

```bash
go run example.go
```

- Или объединённый пример:

```bash
go run example_vars_conditions_functions.go
```
