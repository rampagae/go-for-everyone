## Карты (map)

Карта — как телефонная книжка или словарь: по ключу быстро получаем значение.

### Простыми словами
- Ключ → Значение: например, имя человека → его возраст.
- Очень быстро находить по ключу; порядок обхода не гарантирован.

### Базовые операции
- Создание: `make(map[Key]Value)` или литерал `map[string]int{"Ann": 20}`
- Запись: `m[key] = value`
- Чтение: `v := m[key]`
- Проверка наличия: `v, ok := m[key]` — если `ok == false`, ключа нет
- Удаление: `delete(m, key)`
- Обход: `for k, v := range m { ... }` (порядок случайный)

### Важно
- Нулевая карта — `nil`. В неё нельзя писать (паника). Используйте `make` перед записью.

### Как запустить пример
- Откройте терминал в папке `basics/Карты` и выполните:

```bash
go run example.go
```
