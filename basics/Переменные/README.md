## Переменные

Переменные — это «подписанные коробочки» для хранения значений, которые могут меняться: числа, текст, логические значения и т. д. В реальной жизни переменная — это как счётчик яблок, заметка с текстом или доля от целого числа.

### Как объявлять
- Короткая форма внутри функций: `name := значение`
- Общая форма: `var name = значение` (тип можно указать явно: `var name int = 10`)

### Типы значений (примеры)
- Целые числа: количество страниц в книге, число яблок
- Числа с плавающей запятой: доля от яблока, средняя оценка
- Строки (текст): название книги, имя человека
- Логические значения: да/нет (true/false) — например, «яблоко съедено?»

См. файл `example.go` для наглядного примера и пояснений.

### Про `fmt` — «ящик с инструментами»
`fmt` — стандартный пакет Go для форматирования текста и вывода в консоль. Представьте, что вы техник с ящиком инструментов: когда нужно «сказать» что‑то пользователю или увидеть промежуточный результат, вы достаёте инструмент из `fmt` и выполняете действие (печать строки, числа, нескольких значений). В этом разделе мы используем `fmt`, чтобы показать значения переменных на экране.

### Как переменные живут в памяти (ОЗУ)
- Когда программа запускается, операционная система выделяет ей память (ОЗУ).
- При объявлении переменной компилятор и рантайм решают, где её хранить: в стеке (обычно для локальных, короткоживущих значений) или в куче (если значение «убегает» из функции и живёт дольше).
- Переменная — это имя, связанное с ячейкой памяти. В ячейке лежит значение выбранного типа.
- Адрес ячейки можно представить как «номер коробочки» в ОЗУ, где хранится ваше значение.

### Как значения передаются
- В Go всё передаётся по значению: при передаче в функцию копируется само значение.
- Для типов‑дескрипторов (срез, карта, канал, интерфейс, функция, указатель) копируется «маленькая структура‑ссылка», а данные остаются там, где были. Поэтому можно менять содержимое через ссылку.
- Указатель (pointer) хранит адрес ячейки памяти. Передавая указатель, вы передаёте «как найти исходную коробочку» и можете менять её содержимое.

### Цепочка: от кода до вывода в консоль
1. Вы пишете код, объявляете переменные.
2. Компилятор превращает код в машинные инструкции; при запуске рантайм подготавливает стек и кучу.
3. При присваивании значение записывается в соответствующую ячейку ОЗУ.
4. Когда вы вызываете инструменты из `fmt` (например, печать значений), пакет форматирует данные и записывает байты в стандартный поток вывода (stdout).
5. Операционная система выводит эти байты в терминал, и вы видите текст на экране.

### Как запустить пример
- Откройте терминал (VS Code или системный) в папке `basics/Переменные`.
- Запустите файл напрямую:

```bash
go run example.go
```

- Либо запустите текущий модуль/папку (если там есть `main`):

```bash
go run .
```
