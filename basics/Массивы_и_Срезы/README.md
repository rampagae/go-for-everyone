## Массивы и Срезы

Массив — это фиксированная витрина на N ячеек. Срез — гибкая лента, которая смотрит на массив и может расти.

### Простыми словами
- Массив `[N]T` — жёсткий размер, часть типа.
- Срез `[]T` — длина меняется; хранит ссылку на массив + `len` и `cap`.
- `append` может создать новый массив «за кулисами» и перенести туда данные.

### Полезно знать
- `len` — сколько элементов видно; `cap` — сколько помещается без переразмещения.
- `make([]T, length, capacity)` — создать срез с нужной ёмкостью.
