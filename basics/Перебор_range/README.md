## Перебор (range)

`range` — удобный способ пройти по элементам среза, массива, карты или символам строки.

### Простыми словами
- Для среза/массива: получаем индекс и значение.
- Для карты: ключ и значение (порядок не гарантируется).
- Для строки: позиция в байтах и руна (символ).

### Как запустить пример
- Откройте терминал в папке `basics/Перебор_range` и выполните:

```bash
go run example.go
```
