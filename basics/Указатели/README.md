## Указатели

Представьте, что переменная — это коробочка с ценником. Указатель — это записка с адресом коробочки: «идти по полке, ячейка №123».

### Простыми словами
- `&` — узнать адрес: «где стоит коробочка?»
- `*` — пройти по адресу и взять то, что внутри коробочки.
- Зачем нужны: передать «саму коробочку» в функцию (чтобы менять её содержимое) или не копировать большие данные.

### Важно
- Нулевое значение указателя — `nil` (адреса нет). По `nil` ходить нельзя.
- С указателем вы меняете исходные данные, а не копию.

### Как запустить пример
- Откройте терминал в папке `basics/Указатели` и выполните:

```bash
go run example.go
```
