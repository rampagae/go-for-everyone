### Установка Go и настройка VS Code (кратко по системам)

— Подробный гид см. в разделе «Установка Go и настройка VS Code», здесь — краткая выжимка по ОС.

- Windows:
  - Скачайте установщик с `https://go.dev/dl/` (MSI) и установите по умолчанию
  - Перезапустите терминал (встроенный в VS Code или системный)

- macOS:
  - Вариант 1: установщик с `https://go.dev/dl/` (PKG), затем перезайдите в терминал
  - Вариант 2 (Homebrew): `brew install go` (для Apple Silicon путь Homebrew обычно `/opt/homebrew`)
  - Убедитесь, что путь к `go` доступен в PATH

- Linux:
  - Рекомендовано: архив с `https://go.dev/dl/` → распаковать в `/usr/local` (нужны права администратора)
  - Добавьте `/usr/local/go/bin` в PATH (например, в `~/.profile`), затем перезайдите в терминал
  - Пакетные менеджеры дистрибутива могут ставить устаревшую версию

- Visual Studio Code:
  - Установите VS Code: `https://code.visualstudio.com/`
  - Установите расширение «Go» (автор: Go Team at Google) во вкладке Extensions
  - Через Command Palette выполните «Go: Install/Update Tools» и установите рекомендуемые инструменты (включая `gopls`)
  - В настройках расширения убедитесь, что форматирование и автодополнение включены; при необходимости выберите форматтер и `gopls`

- Проверка установки:
  - Откройте терминал (VS Code или системный) и выполните `go version`
    ```powershell
    go version
    ```
  - Должна отобразиться версия Go. Если команда не найдена, перезайдите в терминал или проверьте переменные окружения PATH.
  - Если команда не находится, добавьте путь к исполняемому файлу `go` в PATH и перезапустите терминал
