## Установка Go и настройка VS Code

Следуйте шагам ниже, чтобы установить Go, подготовить редактор и запустить первую программу.

### 1) Установите Go
- Перейдите на сайт загрузки: `https://go.dev/dl/`
- Скачайте установщик для вашей ОС (Windows/macOS/Linux) и установите по умолчанию

### 2) Проверьте установку
Откройте терминал и выполните:

```powershell
go version
```

Должна отобразиться версия Go. Если команда не найдена, перезайдите в терминал или проверьте переменные окружения PATH.

### 3) Установите VS Code и расширение Go
1. Установите Visual Studio Code: `https://code.visualstudio.com/`
2. Откройте VS Code → вкладка Extensions (или Ctrl+Shift+X)
3. Найдите и установите расширение «Go» (автор: Go Team at Google)

### 4) Поставьте инструменты Go в VS Code
В VS Code откройте Command Palette (Ctrl+Shift+P) → введите «Go: Install/Update Tools» → выберите все рекомендованные инструменты и установите. Это добавит `gopls`, `gofmt`, `goimports`, `dlv` и др.
