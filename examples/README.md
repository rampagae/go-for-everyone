## Примеры и задачки для закрепления

Как работать с задачками
- Создавайте маленькие файлы/мини‑проекты в отдельных папках.
- Запускайте из терминала (VS Code или системный): `go run <файл.go>` или `go run .`
- Печатайте результаты через `fmt`.

### Переменные
1) Объявите три переменные: количество яблок, доля яблока (с плавающей запятой) и имя владельца. Выведите их на экран в одной строке.
2) Поменяйте значение одной из переменных и снова выведите всё.
3) Создайте булеву переменную «хватает ли яблок больше 5» и выведите её.
4) Объясните в комментариях, что лежит в памяти у каждой из переменных.

### Условия
1) Запросите число N (пока можно просто присвоить) и напечатайте «чётное» или «нечётное».
2) По оценке 0–100 выведите категорию: 90+ — A, 80–89 — B, иначе — C или ниже (через `switch`).
3) Если яблок больше 0 и есть доля яблока > 0, напечатайте «есть целые и частичные яблоки», иначе опишите ситуацию.

### Циклы
1) Выведите числа от 1 до 10 включительно (классический счётчик).
2) Посчитайте сумму от 1 до N (переменная N фиксирована в коде).
3) Выведите только чётные числа от 1 до N, пропуская нечётные через `continue`.
4) Пройдитесь `range` по срезу из строк и выведите индекс и значение.

### Функции
1) Напишите `sum(a, b int) int` и выведите результат нескольких вызовов.
2) Напишите `div(a, b int) (int, error)` и обработайте ошибку деления на ноль.
3) Напишите `greet(name string) string`, которая возвращает приветствие, и используйте её.

### Указатели
1) Напишите `increment(p *int)`, меняющую исходное значение по адресу.
2) Реализуйте `swap(a, b *int)` и проверьте, что значения поменялись местами.
3) Создайте указатель `*int`, присвойте ему адрес переменной и выведите значение через `*p`.

### Массивы и Срезы
1) Создайте срез из нескольких чисел, добавьте элементы через `append`, выведите `len` и `cap` до и после.
2) Посчитайте среднее значение элементов среза.
3) Создайте новый срез и скопируйте в него значения из первого (проверьте, что это другая память).

### Карты (map)
1) Создайте карту «имя → возраст». Добавьте 2–3 записи и выведите возраст по имени.
2) Проверьте наличие несуществующего ключа через `v, ok := m[key]` и выведите сообщение.
3) Удалите одну запись и пройдитесь по карте `range`, выведите пары ключ‑значение.

### Строки и Руны
1) Возьмите строку с кириллицей, выведите `len` (в байтах).
2) Пройдитесь `range` по строке и выведите позицию и сам символ.
3) Сконструируйте новую строку, где символы идут в обратном порядке (работайте с рунами).

### Структуры
1) Опишите `Person` с полями `Name`, `Age`. Создайте переменную и выведите поля.
2) Напишите метод `Greeting() string` для `Person` и вызовите его.
3) Создайте срез `[]Person` и выведите только тех, у кого `Age >= 18`.

### defer
1) Выведите порядок работы `fmt.Println` с несколькими `defer` и убедитесь, что порядок LIFO.
2) Сделайте функцию, которая печатает «start», откладывает «cleanup», печатает «work», завершает выполнение.

### Ошибки
1) Реализуйте функцию, которая возвращает ошибку при некорректном вводе (например, деление на ноль).
2) Покажите пример «проброса» ошибки наверх: функция A вызывает B и возвращает ошибку, если B вернула её.

### Перебор range
1) Просуммируйте элементы среза через `range` и выведите результат.
2) Пройдитесь по `map[string]int` и выведите пары; отметьте, что порядок не гарантирован.

### Пакеты и Модули
1) Инициализируйте модуль в отдельной папке (`go mod init example.com/learn`).
2) Создайте пакет `mathx` с функцией `Sum`, импортируйте его в `main` и вызовите.

### Тесты
1) Напишите тест `TestSum` для вашей функции `Sum` из `mathx`.
2) Сделайте табличный тест (несколько входов/ожидаемых результатов) и запустите `go test -v`.

Подсказка: если путаетесь с порядком изучения — вернитесь к «Дорожной карте» в корневом `README.md` и следуйте уровням.
