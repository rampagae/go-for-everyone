## Go для всех

Добро пожаловать! Здесь вы поймёте основы языка Go и научитесь писать простые полезные скрипты и небольшие приложения. Материалы построены от установки окружения до первых программ и дальше — к ключевым концепциям.

### Как начать
Перейдите в раздел [«Установка Go и настройка VS Code»](getting-started/README.md), чтобы поставить Go, настроить редактор и запустить первую программу.

### Что дальше
- Разберитесь с синтаксисом, типами, функциями и пакетами в [«Основах Go»](basics/README.md)
- Посмотрите, как применять знания на практике, в разделе [«Примеры»](examples/README.md)

### Ближайший план
- Сейчас (без кода, только концепции): переменные и константы, условия (`if`/`switch`), циклы (`for`), функции — см. [«Основы Go»](basics/README.md)
- Далее: коллекции (срезы и карты), структура проекта и модули (`go mod`), обработка ошибок
- Практика: небольшие примеры — CLI «echo», минимальный HTTP‑сервер, работа с файлами, параллельные задачи, JSON/HTTP‑клиент — см. [«Примеры»](examples/README.md)

### Требования
- Свежая версия Go (рекомендуется актуальная стабильная)
- Visual Studio Code с расширением Go
